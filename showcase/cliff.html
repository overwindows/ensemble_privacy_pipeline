• Why Stock Plateaus at 6.58–18.13 QPS: With prefix caching active, GPU prefill takes only ~25 ms per request, so host admission (_Parallelism_=1), small batch size (VLLM_MAX_NUM_SEQS=4, bt=8320), and the 37-pass CPU binary-search lock (with self._tok_lock:, ~280 ms per overlong prompt) starve the A100 (52.7%–85.4% SM activity).

In model.py:234, max_num_batched_tokens=8320 is hardcoded to a single sequence's context limit, preventing vLLM from batching more than ~2 concurrent ~3,600-token prefills per step.

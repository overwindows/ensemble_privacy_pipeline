Updating the AgenticGem Prompt & Model Catalog

The catalog is a single self-contained AgenticGem.PromptCatalog.html file — all content, styling, and client-side search/filter logic live in that one file. To update it:

  1. Get the latest source copy. The live file is served behind sign-in at AgenticGem.PromptCatalog.html (sign in with your Microsoft account to view it). The canonical source lives with the site owner; ask for the latest source copy if you don't have it.
  2. Edit the HTML. The datasets live as JS arrays at the bottom of the file:
    • models — the “Model / DLIS” table rows (model, protocol, architecture, used-by, data contract).
    • entries — the prompt entries (scenario, step, name, path, schema, task, model, format, input/output examples).
    • dlisEntries — the supplementary DLIS model-call entries.
    Keep each entry's fields consistent with the schema/structure used by the existing ones.
  3. Test it locally — open the edited .html in a browser (double-click). The search, scenario filter, and expandables are pure client-side JS, so they work with no server.
  4. Publish it — hand the edited file to the site owner to redeploy, or redeploy the site yourself if you have the SWA deployment token (see below).

Deploying updates (agent / site owner)

This site is hosted on Azure Static Web Apps, not a blob. Updates are deployed with the SWA CLI from the local staging folder (which contains all site content + the auth config):

# get the deployment token (as the owner)
az staticwebapp secrets list -n chrona-showcase-internal -g CSE-Showcase-RG

# deploy the whole folder to the production environment
swa deploy ./staging_web --deployment-token "<token>" --env production
Note:
  • The site is gated by Microsoft sign-in via staticwebapp.config.json — anonymous visitors are redirected to /.auth/login/aad before any content is served.
  • Old advert: the previous Azure Blob host (privacypshowcase12114.z19.web.core.windows.net) is now redirect-only — it bounces to this site. Do not upload content back to that blob; it is no longer the host.
  • Full maintenance guide: Q:\ensemble_privacy_pipeline\SHOWCASE_DEPLOY.md.

▶ Updating & deploying this site

Each page is a self-contained static .html file in Q:\ensemble_privacy_pipeline\showcase\ — no build step beyond upload. To add or edit a page:

  1. Edit the .html source in Q:\ensemble_privacy_pipeline\showcase\. Keep data in inline JS arrays so the page works straight off disk.
  2. Restyle for consistency — after regenerating a page, run python Q:\CodeGuru\scripts\fluent_restyle.py to keep the Fluent 2 light theme + shared fl-hub nav.
  3. Test locally — double-click the .html; search/filter are pure client-side JS.
  4. Deploy the WHOLE folder — an SWA deploy replaces the entire site, so stage all files and upload once.

Bugs found & fixed (2026-10-07/08)

Adapter merge was a silent no-op. merge_peft_adapter.py loaded base via AutoModelForCausalLM (427 weight groups) while trainers use Qwen3_5ForConditionalGeneration (760 groups) → 496 adapter keys unmatched (linear_attn.out_proj, in_proj_qkv/z/b/a, mlp.gate/up/down) → zero LoRA deltas applied → every "merged" model = init → identical 0.5249 across all 3 methods. Fix: load base as Qwen3_5ForConditionalGeneration.
Full-param SFT OOM at first optimizer.step. fp32 AdamW on ~8.7B params blew the 79 GB A100. Fix: 8-bit AdamW (bnb.optim.AdamW8bit) + gradient checkpointing + seq-len 6144→1024.
Dependency wall (prior). transformers 5.16.1 + peft 0.21.0 + torch/torchvision ABI mismatch → resolved via --no-deps staged pip + explicit tokenizers==0.23.2 pin + openjev_compat.py Bloom shim.

RecoNF DLIS Inference Models — General, Agentic & Extended Benchmark

Chen Wu · RecoNF EfficientLLM · bench_2026_10 · 2026-10-11
Abstract. We benchmark the three RecoNF DLIS inference models — deepseek-v4-flash, qwen3.8-flash-next (FP8 reasoning), and qwen3.8-27b (non-FP8, H100) — over their OpenAI-compat chat endpoints (auth X-Api-Key). General (MMLU 57-subj, GSM8K, MATH, HumanEval), agentic (BFCL single-turn), and an extended set (MMLU-Pro, ARC-Challenge, BBH, TruthfulQA-mc2). No local GPU/docker: all evaluation is API-driven. GAIA / TAU-bench / SWE-bench were not runnable here (HF-gated GAIA data + docker sandbox required).

  • qwen3.8-flash-next leads all three commonsense benches (0.90-0.99, mean 0.933); qwen3.8-27b close behind (0.893); deepseek trails on commonsense grounding (0.833), matching its lower knowledge/MMLU.
  • WinoGrande required a harness fix (no purity warning dropped). The inspect_evals winogrande task hard-codes GenerateConfig(max_tokens=64) at winogrande.py:102, which silently overrode the model-level max_tokens in our adapter (config.max_tokens or self._max_tokens). The two reasoning models (flash-next, 27b) burned all 64 output tokens on reasoning and emitted an empty ANSWER: — 27b scored a bogus 0.02 (98/100 empty), flash-next 0.03 (90/100 empty). Direct DLIS probes answered correctly at any budget, exposing it as a harness interaction, not model weakness. Fix: override task.config = GenerateConfig(max_tokens=16000) and eval the task object → 27b 0.96, flash-next 0.99 (+96-97 pts recovered), deepseek unchanged (0.84, non-reasoning). This is the 4th harness-artifact-casing-as-weakness (after MMLU-Pro first-letter, GSM8K first-number, BBH terse prompt) — reasoning models need their eval tasks' hard-coded token caps lifted.

Agentic — BFCL Multi-Turn Function Calling 2026-10-10 · n=25 each · 5 V3 cats

The true agentic add-on: BFCL V3 multi-turn categories that require the model to keep calling tools across a multi-step conversation — not just emit one function call in a turn but decide which tool to call next from the tool results, and adapt when the needed function/parameter is only revealed partway through. Scored in-process (python backend, no docker) via inspect_evals multi_turn_match, which checks the full tool-call sequence against the ground-truth call chain. New this session per Chen's ask to keep expanding the agentic benchmarks.

MMLU-Pro is now scored with the official TIGER-AI-Lab/MMLU-Pro protocol (category-tagged prompt + per-category CoT few-shots + "The answer is (X)" extraction), n=140/model (10/cat), from the full parquet (datasets-server first-rows caps at 100 rows = business-only — the very first "MMLU-Pro" was invalid). An earlier custom-runner read (deepseek 0.493, qwen 0.786/0.686) was a harness artifact — see analysis below. BBH: deepseek n=10/task (270), Qwen n=3/task (81). TruthfulQA is a logprob-free mc2 proxy (mark-all-True, graded recall/precision), n=10.

  • MMLU-Pro flips the leaderboard under the official protocol — deepseek is best (0.800). Its apparent "weakness" (0.493) was a harness/config artifact in my custom runner: it omitted the category tag, used bare letter-only few-shots, and extracted the first single letter anywhere in the response (re.search(r"\b([A-J])\b")). DeepSeek is verbose/explanation-first and cites option letters mid-reasoning, so the regex caught stray cited letters and marked correct answers wrong; the terse Qwens didn't trip it. With official framing+extraction, deepseek's hardest cats went 0.1/0.1/0.3 → 0.8/1.0/0.9 (cs/math/engineering), landing 0.80 between the official base 68.3 and instruct 83–86. The Qwen numbers also moved under the official protocol (0.786→0.764, 0.686→0.671), so the original comparison was invalid for all three.
  • BBH 0.707 for deepseek was a PROMPTING artifact, not a genuine weakness (2026-10-10, corrected). The harness forces "Answer the last line only, no explanation" — tuned for terse Qwen — which strangles DeepSeek's chain-of-thought and makes it collapse to a default (F) (confirmed NOT a cache artifact). Full CoT-permitting 3-model re-run (same grader, only the prompt changed) corrects BBH to deepseek 0.944, flash-next 0.996, 27b 0.985 — deepseek jumps +24pts and is now statistically tied with both Qwens (27b even dipped 0.993→0.985, its terse score was prompt-boosted). Same artifact family as the MMLU-Pro first-letter extractor and GSM8K first-number grader: this benchmark needs CoT-permitting prompts for explanation-first models.
  • TruthfulQA splits the field (the real signal): both Qwens low recall (0.49–0.51, F1 0.65–0.68, precision 1.0 — they only answer high-confidence); deepseek highest TruthfulQA (recall 0.92, F1 0.91) — says "NONE", more calibrated/honest. ARC is a wash (all 0.9).

  • GAIA: data is HF-gated (no token → 401 GatedRepoError) — not run.
  • TAU-bench / SWE-bench-Lite: require a docker sandbox; no docker on wuc's box — not run.

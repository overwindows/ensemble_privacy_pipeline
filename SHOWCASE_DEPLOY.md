# Chrona Showcase — Deploy & Add-a-Page Guide

This repo now hosts the **Chrona** showcase site, published via **Azure Blob static
website hosting**. Live at:
**https://privacypshowcase12114.z19.web.core.windows.net/**

> The original ensemble-privacy research code was removed from this repo — it is no longer
> part of this project. See the git history or the old `overwindows/ensemble_privacy_pipeline`
> tags if you ever need it. This repo is now a *webapp-only* project.

## Why blob hosting (not App Service)
Our Azure subscription enforces Microsoft policy **`MAI_AzureSites-v010`** ("Deny Azure web
apps with public network access"), which **denies** App Service web apps that are public
without auth. **Azure Blob static website hosting is not affected** — it's public by default
and serves over HTTPS.

## The core workflow: drop a file in `$web` and it's live
The **`$web` container is the online folder.** Upload any file there and it's served
immediately at `<endpoint>/<filename>` — no build, no redeploy. Verified end-to-end
(upload → live 200 instantly; delete → 404 instantly).

To add a one-off page, just upload a ready `.html` file to `$web`; its name becomes the
URL path (`mypage.html` → `.../mypage.html`).

## How to edit the site's content
The main pages (Overview, Results, Roadmap, Brainstorm, Demo) are generated by
`build_static.py` from the seed data in `db.py`.

1. Edit `db.py` — add/change a `Page` + `Section`s. `slug` = URL path, `nav_label` = nav bar.
2. `python build_static.py` — regenerates `dist/`.
3. Upload `dist/` to the `$web` container (see below).

## Publish a build to the live site
```bash
cd <this repo>
python build_static.py

KEY=$(az storage account keys list -n privacypshowcase12114 -g CSE-Showcase-RG --query "[0].value" -o tsv)
export AZURE_STORAGE_CONNECTION_STRING="DefaultEndpointsProtocol=https;AccountName=privacypshowcase12114;AccountKey=${KEY};EndpointSuffix=core.windows.net"
az storage blob upload-batch -d '$web' -s dist --connection-string "$AZURE_STORAGE_CONNECTION_STRING" --overwrite
```

## Create a brand-new showcase for another project (reusable recipe)
Full cross-project recipe: `Q:\CodeGuru\knowledgebase\16_SHOWCASE_WEBAPP_RECIPE.md`.
Repeat the setup with a new unique storage account name, drop content into its `$web`, and
share the new `<account>.zN.web.core.windows.net` endpoint.

## Constraints / gotchas
- **No server-side logic.** Blob static hosting has no serverless API/backend — anything
  dynamic must run in the browser (JS). The redaction demo runs **client-side** in `demo.js`.
- **Custom domain** needs DNS you control (+ Front Door in front for the padlock). Without
  custom DNS we use the free `.web.core.windows.net` URL.
- `*.json` is gitignored by this repo's `.gitignore` (needs `git add -f` if you ever re-add
  config json, e.g. `staticwebapp.config.json`).
- Index doc is `index.html` (served at `/`); missing pages fall back to `404.html`.
